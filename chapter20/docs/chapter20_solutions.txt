c) char (*)av[] is syntactically correct. We want an array of pointers to strings,  not a single char *.
The compiler gives the error:
./src/exercises.c:16:33: error: expected ‘;’, ‘,’ or ‘)’ before ‘av’
because it treats as char(*) as one complete expression and expects more args with ',' or a closing bracket. It either expects variable inside the brackets or something else. 
For a single pointer to char array, char (*av)[].
For an array of pointers to strings, char *av[], which is what main expects.
